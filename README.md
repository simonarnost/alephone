# ℵ₁ alephone

Personal site of Šimon Arnošt — [simonarnost.github.io/alephone](https://simonarnost.github.io/alephone/).

Built with [Astro](https://astro.build), deployed to GitHub Pages on every push to `main`.

```bash
npm install
npm run dev      # http://localhost:4321/alephone/
npm run build    # type-check + build to dist/
```

Content lives in `src/data/` (CV, projects, now page) and `src/pages/`.
